CSSR.IN NEXT.JS + PRISMA + NEON

1. Copy .env.example to .env and add your Neon pooled and direct URLs.
2. Generate a new JWT_SECRET using: openssl rand -hex 32
3. Set ADMIN_EMAIL and a unique ADMIN_PASSWORD (12+ characters).
4. Run: npm install
5. Run: npm run db:generate
6. Run: npm run db:push
7. Run: npm run db:seed
8. Run: npm run dev
9. Open http://localhost:3000
10. Push to GitHub and import ONE repository as ONE Next.js project in Vercel.

Read README.md for Vercel environment variables, Blob uploads, security and troubleshooting.
